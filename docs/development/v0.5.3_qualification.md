# v0.5.3 qualification

## Scope

Reference providers may be valid self-contained QC, full-run or cohort-update
publications within the declared permanent provider root. FastANI output and
cohort-update history no longer disqualify them. The change removes the same two
exclusions from the Nextflow controller and Python importer; existing ownership,
boundary, content, relative-link and final-acceptance checks remain unchanged.
There are no new options, validation passes, scientific methods or image changes.

## Development checks

- The new FastANI/history provider cases failed under the previous rule.
- All 27 targeted reference, import, relocation and validation-sharing checks
  passed in the locked macOS environment. The pinned Linux helper passed 26,
  skipping only the Nextflow-dependent code-identity check.
- Seven Nextflow workflow runs passed with input-driven tool fixtures. They cover
  full-run and self-contained cohort-update providers, reference/copy table
  equality, zero copied/cloned sample files, chained references, independent
  materialisation and reannotation. Provider bytes remained unchanged.
- Existing corruption, missing-provider, retargeted-link, circular-reference and
  boundary-escape controls still reject invalid inputs. Relocation with FastANI
  output and cohort-update history also passed.
- Repository-wide Ruff and ty, helper integration and Viper configuration checks
  passed. These are storage-policy controls; no new biological qualification is
  claimed for the unchanged scientific tools.
