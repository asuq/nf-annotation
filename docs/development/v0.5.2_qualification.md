# v0.5.2 qualification

## Scope

- Map compliant Prokka contigs through the complete retained input order and
  masked DNA, preserving exact and ambiguity-masked duplicates as distinct
  source contigs. Keep coordinate and translation checks.
- Stage reversible CRISPRCasFinder headers for every sample. Retain native JSON
  and the mapping ledger; restore complete source identities without JSON repair.
  Failed or incomplete output remains distinguishable from a valid zero result.
- Apply reviewed genetic codes only to matching accessions and ordered FASTA
  identities with valid paired CheckM2 evidence. Record automatic and effective
  calls and replay reviewed decisions during reuse.
- Apply Ruff and ty across owned Python sources, tests and container helpers.
  Preserve scientific thresholds, tool arguments, default runtime dependencies,
  database resources and image pins.
