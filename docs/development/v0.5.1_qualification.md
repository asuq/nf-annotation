# v0.5.1 qualification

## Scope

- Reuse verified preparation receipts without runtime database scans. Database
  file receipts and prepared local SIF identities use MD5; OCI digests retain
  their registry-defined format.
- Copy eggNOG annotation databases to task scratch after the pooled search,
  keeping the DIAMOND index linked. Ordinary runs and recovery share this code.
- Recover only unfinished per-proteome annotations from a validated failed packet.
  Preserve completed search/member bytes and original failure provenance.
- Keep biological arguments, confidence rules, ANI/AAI methods and image pins unchanged.

## Development checks

- The locked regression gate ran 705 tests: 698 passed, seven optional checks skipped.
  An affected local test group was rerun after correcting its multiprocessing launcher;
  the invalid attempt is excluded from these totals.
- Fourteen Linux execution/recovery controls passed in the pinned eggNOG image.
  These use synthetic native callers and do not establish biological accuracy.
- Helper integration and Viper configuration checks passed.
- The native pilot exposed one remaining SHA-only batch validator after the MD5
  receipt change. Commit `16c8f6e` corrected it. All 16 focused checks passed,
  including a complete Nextflow annotation case using local SIF receipts.

## Native pilot

- All 17 case/phase receipts passed. The controller and 869 unique recorded
  workers completed with exit zero; historical failures and operator-cancelled
  work remain separate from this successful accounting.
- Fresh QC/gene prediction covered three ten-genome cohorts. Native ANI/AAI
  covered cumulative 10/20/30-genome cohorts, self-contained publication,
  identical resume and cutoff/scoring-only changes.
- All 19 representatives passed eggNOG, Pfam and KOfam: 57 successful results.
  Four earlier completed searches were genuinely cached during the authorised
  concurrency restart; four ordinary eggNOG batches completed with local database receipts.
- Matching annotation reuse/resume, clustering from annotated QC, reference
  reannotation and 600 relocated reference links passed.
- Positive full-stage reuse used a genuine two-genome full-source control with
  native CRISPR evidence. QC-only sources remain unsupported for full-stage reuse.
- The pilot began at `338f4cf` and continued at `16c8f6e` after the planner fix.
  Completed scientific work was retained. The final release packaging changes
  only version metadata and documentation.

Native execution and acceptance establish operational qualification for these
controls, not universal annotation or taxonomic accuracy. Small reports were
mirrored and all 167 remote/local file hashes matched. Detailed run identifiers,
inputs and logs remain in the private qualification archive.

## Upgrade and production

Prepare schema-2 database receipts and adjacent SIF receipts before deployment.
Earlier annotation method/cache identities are not a compatibility target;
recovery requires the same prepared resources and execution method.

The production master checksum remained unchanged. This qualification did not
restart production, rewrite its data, or replace earlier releases.
