# v0.4.4 qualification record

Qualification date: 2026-10-25. The release is based on official v0.4.3
(`7af2465724551b618e7669c967204ed1ddfbea4c`) and retains nf-helper
`36c4148f975aa76008e48214f4fea1dad8e78f9b`. Dependencies, scientific images,
ANI formula/thresholds, CheckM2 code-selection rules and native identifier
conventions are unchanged. See the [interface and migration guide](../domain_stages.md).

## Release checks

The replacement CLI's locked Python/Nextflow suite completed 605 tests with
seven optional skips and no failures. Focused policy, CLI, domain-stage and
native-argument wrapper checks also passed, including all three domain modes,
rejection of omitted/obsolete options, and the database-preparation and
annotation-only exemptions. The 22 acceptance-harness tests passed.

The helper-integration and explicit Viper configuration checks passed; the
resolved manifest version was `0.4.4` and `params.domain` had no default.
Scoped Ruff checks and `uv lock --check --offline` passed. Publication additionally
requires smoke checks from a fresh checkout of the exact replacement commit;
the GitHub release notes record their outcome.

## Implementation controls

Real Nextflow integration tests use explicit synthetic external-tool substitutes
to verify separate bacterial and archaeal QC publications, their cumulative ANI
run after deleting the original work directories, matched primary BUSCO results,
code-4/code-11 routing, missing-code skips and low-quality exclusions. QC and ANI
stages suppress functional searches even when annotation tools are configured.
ANI-only runs reject unpublished samples. Changed profiles, missing/conflicting
domain metadata and attempts to assign a domain to unrecorded legacy evidence
are rejected. A separate resume control changes only the imported policy helper
and verifies that validation runs again.

Native-command wrapper controls verify explicit Prokka kingdoms and genetic
codes and Barrnap models. Codetta staging controls execute the real module with
synthetic callers: a reference directory named `codetta` retains its checksums,
and a symlink at the output location fails before any writes.

The reporting/source-import unit controls include CSV metadata despite the staged
`.tsv` suffix, reserved scope-column collisions, and supplemental metadata that
must not override internal reuse fields. These tests distinguish unrequested,
unavailable, filtered and failed evidence.

## Limits

These controls establish implementation and runtime compatibility. They do not
establish biological accuracy on archaeal genomes, appropriateness of an
operator-selected custom BUSCO lineage, or performance at collection scale.
Native BUSCO datasets were not rerun for this change; routing and matched-score
selection were checked with controlled inputs, while the native BUSCO method
and prepared-resource contract remain unchanged. A representative real-data
pilot remains necessary before scaling a new domain/profile combination.

Seven optional Docker image-build/contract tests are disabled in the standard
suite. The separate native smoke above uses existing public images and does
not rebuild them. No new image publication is needed for this release.
